# موسوعة قلم — Qalam Encyclopedia (AR/FR/EN)

قلم المعرفة • La plume du savoir • The pen of knowledge — موسوعة تعليمية تفاعلية ثلاثية اللغات
تعمل دون اتصال، بروح Encarta وبتقنيات حديثة.

## الميزات الحالية / Features

1. **قارئ مقالات ثلاثي اللغات** — عربي (RTL) / Français / English مع تبديل فوري يحفظ موضع القراءة.
2. **بحث فوري موحد** عبر اللغات الثلاث (مع تطبيع الحروف العربية).
3. **اختبار تكيفي** — صعوبة الأسئلة تتكيف مع أداء المتعلم.
4. **المكتبة الشاملة (Kiwix/ZIM)** — تشغيل ويكيبيديا وفيكيديا كاملة دون اتصال:
   - مدير تنزيل داخلي مع شريط تقدم (يكتب إلى `public/zim/`).
   - خدمة نطاقات HTTP (Range) ضرورية لقارئ Kiwix.
   - الكتالوج يتضمن النسخ الكاملة (3+ غيغابايت) للتنزيل عند الحاجة.
   - ملفات ZIM غير مضمّنة في Git؛ حجم بعضها يتجاوز حد GitHub البالغ 100 ميغابايت للملف الواحد. نزّلها من داخل التطبيق محليًا عند الحاجة.
5. **محرر المعلم** — مقالات جديدة بثلاث لغات + ترجمة تلقائية (عبر محرك الذكاء) +
   تخزين محلي + تصدير/استيراد JSON.
6. **المعلم الذكي** — محادثة مع ثلاثة محركات قابلة للاختيار:
   - دون اتصال (إجابات من المقالات المحلية)، Ollama محلي، أو أي API متوافق مع OpenAI
   (OpenAI / DeepSeek / Groq…). الإعدادات تُحفظ محلياً.
7. **PWA** — Service Worker يعمل دون اتصال (يستثني ملفات ZIM والواجهة البرمجية من التخزين المؤقت).
8. **وسائط تفاعلية داخل صفحة المقال** بحسب موضوعه:
   - **استكشاف ثلاثي الأبعاد (three.js)** — مشاهد إجرائية: النظام الشمسي، الذرة، القلب
     النابض (منزلق نبضات)، جزيء الماء المهتز، الأهرامات (تفكيك + إظهار الغرف الداخلية)،
     وكرة أرضية بأفريقيا بارزة (من بيانات Natural Earth، انقر على دولة لتعرف اسمها).
     تحكم بالسحب والتقريب، وتفكيك/تركيب، ومنزلق سرعة.
   - **رسم تفاعلي SVG** — دورة الماء بخطوات، تشريح القلب، بنية الذرة، مقطع الهرم،
     خريطة أفريقيا تفاعلية (انقر على دولة)، ومخطط أبعاد الكواكب.
   - **رسوم بيانية** — أعمدة ودوائر (أقطار الكواكب، توزيع الماء، نبضات القلب…).
   - **أزرار ذكاء اصطناعي** — «اشرح لي أبسط» و«اطرح عليّ أسئلة» تستدعي محرك المعلم
     (أو تعطي بديلاً محلياً دون اتصال).
   - **رحلة زمنية ومكانية تجريبية** في مقال الشمس: من بدايات الكون إلى أدلة الحياة المبكرة، مع شرح مبسط للأطفال وشرح أعمق، وروابط NASA لكل محطة، بجوار مشهد النظام الشمسي ثلاثي الأبعاد.
9. **واجهة مجددة** — قسم بطولي متدرج الألوان، بطاقات متحركة، هوية Encarta العصرية.

## التشغيل / Run

```bash
pnpm install      # + patch تلقائي لبيئات sandbox
pnpm dev          # http://localhost:5173
pnpm build        # tsc --noEmit + vite build → dist/
```

## النشر / Deployment

- عند تفعيل GitHub Pages من **Settings → Pages → GitHub Actions**، يبني سير العمل `.github/workflows/deploy-pages.yml` الموقع وينشره تلقائيًا من فرع `main` على `https://zoulouti-cell.github.io/Qalam/`.
- في إعداد GitHub Pages، يجب اختيار **GitHub Actions** مصدرًا للنشر حتى يعمل سير العمل.
- يتضمن المستودع كود الواجهة والبيانات والأصول المرئية الصغيرة، ولا يتضمن ملفات ZIM أو إعدادات `.npmrc` الخاصة بجهاز المطوّر.
- واجهات إدارة مكتبة ZIM (`/api/zim-list` والتنزيل وتقديم النطاقات) تعمل عبر إضافة Vite أثناء التطوير؛ يلزم توفير واجهة خادم مكافئة قبل نشر نسخة إنتاجية تعتمد على تنزيل أو قراءة أرشيفات ZIM.
- راجع `docs/CONTENT_PROVENANCE.md` و`public/assets/media-manifest.json` لاستكمال مراجعة مصادر تراخيص الوسائط قبل إعادة توزيعها.

**ملاحظة بيئة العمل (Windows sandbox):** هذه البيئة تمنع العمليات الفرعية ذات الأنابيب،
لذلك المكدس مبني على Vite 8 (محرك rolldown/oxc داخل العملية، بلا esbuild/SWC)، مع ترقيع
تلقائي (`scripts/patch-vite.cjs` عبر postinstall) يتجاوز استدعاء `net use` في vite.
على جهاز عادي يمكنك استخدام أي Vite/إعدادات بدون هذه الترقيعة.

## محتوى الموسوعة / Content layers

ثلاث طبقات:

1. **المكتبات دون اتصال (ZIM)** — `public/zim/` — آلاف المقالات عبر قارئ Kiwix:
   ويكيبيديا عربية (أهم المقالات + التاريخ)، فيكيديا فرنسية، فيكيديا إنجليزية.
2. **الطبقة المنسقة** — 10 مقالات أصلية مصممة يدوياً (بوسائط 3D ورسوم ومستويات) +
   **مئات المقالات المدرسية المستوردة** من ويكيبيديا بثلاث لغات (`public/data/wikiArticles.json`).
  تظهر روابط المصادر والترخيص لكل مقتطف؛ وتضيف عمليات التحديث الجديدة رقم المراجعة وتاريخها.
   لإعادة الاستيراد أو توسيعه:
   ```bash
   node scripts/fetch_wiki.cjs       # القائمة المدرسية الأساسية (50 موضوعاً)
   node scripts/fetch_wiki_cats.cjs  # الحصاد من تصنيفات ويكيبيديا العربية (34 تصنيفاً)
   ```
   (طلبات مجمعة 20 عنواناً + مهلة 800ms + إعادة محاولة — تحترم قيود ويكيبيديا).

سياسة توثيق المحتوى والوسائط: `docs/CONTENT_PROVENANCE.md`.
توظيف بنية Encarta دون خلط نصوصها ووسائطها بالمحتوى المنشور: `docs/ENCARTA_TO_QALAM.md`.
3. **مولّد المعرفة** — مقالات لا نهائية بالذكاء الاصطناعي (يتطلب محركاً في إعدادات المعلم).

المحتوى المستورد من ويكيبيديا مرخّص **CC BY-SA** (يظهر التنويه في تذييل التطبيق).

## البنية / Structure

- `src/App.tsx` — الواجهة والمسارات (#/, #/quiz, #/library, #/tutor, #/editor)
- `src/i18n.ts` — قاموس اللغات الثلاث + تطبيع البحث
- `src/data.ts` — المقالات والأسئلة التجريبية
- `src/zimlib.ts` — كتالوج ZIM + روابط قارئ Kiwix
- `src/ai.ts` — محركات المعلم الذكي (offline / Ollama / OpenAI-compatible) + الترجمة
- `src/storage.ts` — مقالات المعلمين وإعدادات الذكاء (localStorage)
- `public/kiwix/` — قارئ Kiwix JS (من مستودع kiwix/kiwix-js الرسمي)
- `public/zim/` — ملفات ZIM (تُنزَّل من داخل التطبيق)
- `vite.config.ts` — إضافة `zim-api`: قائمة الملفات + تنزيل بالبث + خدمة Range
